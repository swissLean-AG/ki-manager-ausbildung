Keine Cookies, keine Tracker

Diese Website setzt keine Cookies und keine Tracker ein. Es gibt keine Analyse- und Werbedienste, keine Zählpixel und keine Nutzerprofile. Wir messen nicht, wer die Seite besucht.

Schriften, Bilder und Videos vom selben Server

Schriften, Bilder und Videos liegen auf demselben Server wie die Seite selbst. Beim Aufruf werden keine Inhalte von Drittanbietern nachgeladen. Videos starten erst, wenn du sie anklickst, und werden ebenfalls von diesem Server geliefert.

Auslieferung der Seite

Die Seite wird über GitHub Pages ausgeliefert, einen Dienst der GitHub Inc. in den USA. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie deine IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen. Die swissLean AG wertet diese Daten nicht aus.

Anmeldung

Terminbuchung über Microsoft Bookings

Der Knopf zur Buchung eines Infogesprächs per Teams öffnet den Buchungskalender von Microsoft Bookings in einem neuen Tab. Erst mit diesem Klick verlässt du diese Seite. Was du dort eingibst, etwa Name, E-Mail-Adresse, Telefonnummer und Anliegen, geht an Microsoft und an die swissLean AG, damit wir den Termin bestätigen und das Gespräch führen können. Für die Verarbeitung durch Microsoft gilt die Datenschutz­erklärung von Microsoft.

Videos ohne Vimeo

Die Videoausschnitte auf dieser Seite kommen von unserem eigenen Server. Vimeo wird nicht aufgerufen, auch nicht beim Abspielen.
